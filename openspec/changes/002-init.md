# 002 - 语言版本管理（Profiles + 一键安装）

## 1. 目标

- 面向“干净电脑环境”的首次上手：用户无需先手动研究 nvm/fnm/pyenv/rustup 等工具，FoPanel 提供可选方案与引导。
- 统一入口做“语言版本管理”：以“配置文件（Profile）”描述一组语言 + 安装器 + 版本，并支持保存多个配置。
- 提供“默认配置 + 一键安装”：例如 `Node(fn m)+22.0.0` 等，用户一键安装后即可开始开发。

## 2. 核心概念

- 安装器（Installer）：例如 Node 的 `fnm/nvm`、Python 的 `pyenv`、Rust 的 `rustup`。
- 配置文件（Profile）：一个可复用的安装清单，包含多个条目（Item），每个条目描述：
  - 语言（language）
  - 安装器（installer）
  - 版本（version）

## 3. 功能规格

### 3.1 版本管理页（UI）

- 新增“版本管理”入口，打开后提供：
  - 选择/创建/删除配置文件（Profile）
  - 编辑配置文件条目（增删语言条目、选择安装器、填写版本）
  - 一键安装：按条目逐个安装，并展示每一步输出与结果
- 提供一个默认配置（可直接一键安装）。

### 3.2 安装器可用性检测与引导

- FoPanel 需要区分两种状态：
  - 设备已安装某安装器：可直接安装语言版本。
  - 设备未安装某安装器：FoPanel 需要给出“按系统区分”的安装建议命令（复制即可执行）。
- 命令生成需要兼容 macOS/Windows（Linux 可后续补齐，但结构需预留）。

### 3.3 安装执行策略

- 一键安装本质为“串行任务队列”，每条 Item 调用后端安装命令：
  - Node：`fnm install <version>` 或 `nvm install <version>`
  - Python：`pyenv install -s <version>`
  - Rust：`rustup toolchain install <version>`
- 若某条 Item 的安装器不可用，则该条显示“阻塞原因”，用户先安装管理器后重试。

## 4. 数据持久化

- Profile 保存为应用数据目录内的 JSON 文件（可跨平台）：
  - 支持多个配置文件
  - 支持默认配置（首次启动自动生成）

## 5. 非目标（暂不做）

- 不在 FoPanel 内“接管终端的版本切换/激活”（避免与 fnm/pyenv 的 hook 冲突）。
- 不做全盘遍历硬盘的可执行文件扫描（采用“常见路径 + 管理器 + PATH”组合扫描策略）。
